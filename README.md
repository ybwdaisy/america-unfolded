# America Unfolded

> Explore American history through maps.

An interactive historical cartography application illustrating the territorial expansion of the United States from 1776 to 1959.

## Overview
This repository contains the source code, historical boundary datasets, and documentation for **America Unfolded**.

- **Focus**: Territorial expansion and boundary formation (1776–1959)
- **Status**: Development branch `feature/territory-map-v1`
